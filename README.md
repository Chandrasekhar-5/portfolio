# Chandrasekhar — Frontend Portfolio

A high-performance, animation-driven personal portfolio built with **pure HTML, CSS, and Vanilla JavaScript**.  
Designed to showcase projects, skills, and UI engineering with a strong focus on **motion, performance, and UX polish**.

> No frameworks. No libraries. Just clean architecture and modern frontend engineering.

---

## ✨ Features

- ⚡ **Smooth scroll-based animations** (custom easing & velocity-based effects)
- 🎯 **Sticky Home → About stacking transition**
- 🌙 **Dark / Light mode** with persistent state
- 🧭 **Dynamic navigation underline & active section tracking**
- 📊 **Scroll progress indicator**
- 🖱️ **Cursor glow interaction (desktop-only)**
- 📱 **Fully responsive** (mobile, tablet, desktop)
- 🧩 **Modular JavaScript architecture**
- 🪟 **Project modals with detailed views**
- 💾 **LocalStorage usage** (theme, UI state)
- 🚀 **Zero backend, zero frameworks**

---

## 🧠 Tech Stack

**Frontend**
- HTML5  
- CSS3 (Custom properties, animations, responsive design)
- Vanilla JavaScript (ES6+)

**Concepts Used**
- Intersection Observer
- Custom scroll interpolation
- Modular JS architecture
- DOM performance optimizations
- Accessibility-friendly UI patterns
